# PhysiX screen target workspace

Each numbered folder owns the visual target for one public route or state family. Keep selected reference imagery, generated iterations and parity notes here; do not create another frontend/prototype tree.

| Folder | Scope |
|---|---|
| `01-home` | Home upper/lower scroll composition, finder, issues, services, Charlie and dock. |
| `02-book-service` | Book entry and service selection. |
| `03-service-detail` | Service hero, explanation, first-visit summary and Book handoff. |
| `04-online` | Online consultation public page. |
| `05-about-charlie` | Practitioner/about page. |
| `06-first-visit-faq` | First-visit information and FAQ. |
| `07-booking-time` | Focused booking shell, date/time selection or unavailable state. |
| `08-booking-details` | Contact/details form and verification substate. |
| `09-booking-review` | Final authoritative booking summary. |
| `10-booking-confirmation` | Persisted-booking success and message-delivery distinction. |
| `11-menu-search` | Full-height menu and service-finder/search states. |
| `12-system-states` | Loading, empty, provider error, slot conflict and recovery states. |
| `13-account-entry` | Public handoff into retained Gymaf; no Gymaf redesign. |

Preferred files per folder: `reference.png`, `generated-vNN.png`, `spec.md`, `acceptance.md`. Existing `.gitkeep` files only preserve the directories until the targets are exported.
