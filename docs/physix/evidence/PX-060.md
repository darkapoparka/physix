- Search submission dismisses input focus; on coarse-pointer devices the dock is hidden while the search input is focused. No claim of physical keyboard/device qualification.
- Cross-engine checks exposed menu-trigger focus restoration on touch/WebKit. The exact opening button is now recorded, rather than relying on browser click-focus defaults.
